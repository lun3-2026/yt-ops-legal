yt-ops プライバシーポリシー / Privacy Policy

制定日: 2026年10月11日 / Effective: October 11, 2026

1. 利用者

yt-ops は VOLO が自社の YouTube チャンネルを運営するためだけに使う社内ツールです。VOLO 以外の利用者はいません。

2. 取得する情報

Google の OAuth で VOLO 自身が許可した範囲で、YouTube API Services を通じて次の情報を扱います: 自社チャンネルの基本情報と状態、自社チャンネルの動画とその公開設定・説明文、自社動画へのコメント、自社チャンネルの再生回数などの分析データ。

3. 使い道

自社動画のアップロード・予約公開・情報の更新・非公開化、および自社チャンネルの成績の分析にだけ使います。広告配信や第三者への提供・販売には使いません。

4. 保存と共有

取得した情報と認証トークンは、VOLO が管理する端末にだけ保存し、アクセス権を運営者に限っています。第三者とは共有しません。分析データは取得から30日以内に更新するか削除します。

5. 許可の取り消し

許可はいつでも Google アカウントの「サードパーティ製のアプリとサービス」から取り消せます。取り消した場合、保存していたトークンは使えなくなり、VOLO が削除します。

6. 関連する規約

yt-ops は YouTube API Services を使っています。YouTube 利用規約と Google プライバシーポリシーもあわせてご確認ください。
